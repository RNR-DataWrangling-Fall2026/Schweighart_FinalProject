# Schweighart_FinalProject

## Data Wrangling final project repo

This is the repository for my final project in Data Wrangling which doubles as my independent study!

This data comes from several studies performed in the 1970s. It contains data about rodents in Saguaro National Monument, both East and West. There is a second set of data that documented the contents of seed pouches for certain rodents captured in the first study.

I currently have 4 sub-directories, including a code folder, data_raw and data_clean folders, and an images folder. Data_raw contains .csv files that need to be cleaned, while data_clean only contains data that is ready to be worked with. The images folder will hold any plots I make using this data.
